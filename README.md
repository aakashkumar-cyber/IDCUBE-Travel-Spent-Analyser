# IDCUBE Travel Spend Analyser

Flight, hotel, rail and wallet spend dashboard (MakeMyTrip myBiz ledger data, FY-wise Apr–Mar).

- `index.html` — fully self-contained dashboard (data embedded). Open directly or host via GitHub Pages.
- Data through 13 Oct 2026.
- Shared bookings split equally among co-travellers; duplicate name spellings merged.
- Every section exports to Excel and PDF.

Designed & built by CA Aakash Kasotia.
